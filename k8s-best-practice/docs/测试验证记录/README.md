## 版本号规则

版本号是发布身份，不是测试迭代计数器。完整规则见 [发布 Chart 到 OCI 仓库](../附录/发布Chart到仓库.md)，要点：

- 生产版本用正式版本号（`0.2.1` → 下一版 `0.2.2`）。
- 测试候选用预发布后缀并按序递增：`0.2.2-rc.1`、`0.2.2-rc.2`……（semver 上 `0.2.2-rc.1 < 0.2.2`）。
- 测试候选只推版本 tag，**不更新 `latest`**；`latest` 只指向生产 GA 版本。
- 禁止同版本覆盖重推；改一行代码也要升版本号。
- 文件名格式：`categraf-<Chart 版本>-<YYYYMMDD>.md`，其中版本号与 `Chart.yaml` 的 `version` 一致。

## 记录格式

每条记录至少包含：

1. 测试日期、测试人、变更范围。
2. 测试环境：Flashcat、Kubernetes、节点、操作系统、容器运行时和 Helm 版本。
3. 被测产物：Chart/Operator 版本、镜像、包 SHA256、OCI Digest。
4. 测试步骤与每步结果。
5. 已知限制、影响面和回滚方式。
6. 不在文档中记录密码、Token、Secret 明文。
